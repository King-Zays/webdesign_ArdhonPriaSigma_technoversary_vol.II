# BONI — Bank Observasi Nol Emisi

BONI adalah rancangan website bank sampah digital untuk Web Design Competition Techno Versary Vol. II 2026 dengan tema **EcoDigital For Environment**. BONI membantu warga mengenali sampah yang bisa disetor, menyiapkan material, dan memahami proses setoran dari pemilahan hingga pencatatan berat.

## Rancangan awal

- **Beranda** memperkenalkan BONI dan mengarahkan pengunjung ke panduan pemilahan atau simulasi setoran.
- **Tentang** menjelaskan cara kerja bank sampah serta peran warga dan pengepul.
- **Edukasi** menyajikan panduan mempersiapkan material awal seperti botol PET dan kardus.
- **Kontak** menyediakan kanal untuk pertanyaan dan kolaborasi.
- **Simulasi setoran** menunjukkan alur memilih material, memasukkan perkiraan berat, dan melihat ringkasan setoran dengan data contoh.

## Pengembangan

Repo ini berisi rancangan awal. Petunjuk instalasi dan cara menjalankan website akan ditambahkan bersama implementasi pertama.
